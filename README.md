# Sing-box NAT

一个脚本，在你的服务器上一键搭好代理，自带中文菜单。支持 16 种协议、订阅链接、Argo 内网穿透，**没有公网端口的 NAT 小鸡也能用**。

**V3.9.31**

支持 Debian / Ubuntu / CentOS / Alpine / Arch，systemd / OpenRC / 无 init 都能跑。

---

## 一分钟安装

```bash
wget -qO sb.sh https://raw.githubusercontent.com/87954621/SingBox/refs/heads/main/sing-box.sh && bash sb.sh
```

装完按提示选内核（一般选 `1`）、输入 `y` 确认即可。全程两道提问。

> **不要用 `wget -qO- 地址 | bash` 这种一行管道**：脚本要问你选内核、确认安装，管道会把脚本内容当成你的输入吞掉，导致"明明没选却自动往下装"。一定要先下载成文件再 `bash sb.sh`。

安装时它只补几个必要的工具（缺什么装什么，都列给你看）；二维码、dig 这些可选的不会偷偷装，用到时再问你。订阅服务默认不开。

## 日常命令

```bash
sb            # 打开管理菜单
sb version    # 看版本
sb update     # 更新管理器（重要：脚本升级后必须跑一次，见下方说明）
sb check      # 检查有没有新版本
sb help       # 帮助
```

> `sb` 命令是安装时的快照。如果你更新了脚本文件，要跑一次 `sb update`，菜单才会用上新功能。

## 管理菜单

输入 `sb` 打开，菜单长这样（编号固定，方便记）：

| 编号 | 功能 |
|---|---|
| `1` / `2` | 部署单个协议 / 批量部署 |
| `3` | 节点管理（改端口、复制链接、扫码、改名、删除） |
| `4` / `5` | 端口范围 / 网络检测 |
| `6` | **入站 IP 和端口映射**（客户端连不上时先看这里） |
| `7` | 客户端设置（指纹、SNI、证书、Clash 分流） |
| `8` | 服务管理（启停、重启、内存模式） |
| `9` | 内核管理（升级、重装、卸载内核） |
| `10` / `11` | 导出链接 / 订阅服务 |
| `12` | Argo 隧道 |
| `13`–`16` | 系统信息 / 自检修复 / 完全卸载 / 检查更新 |
| `0` | 退出 |

**快捷键**：不想记编号，直接输入字母也行——

- `r` 重启服务
- `e` 一键导出所有客户端配置
- `s` 查看服务状态
- `v` 查看内核版本

菜单顶部会实时显示服务是否在跑、几个节点、内存和 CPU 占用。

## 订阅链接

打开订阅服务（菜单 `11`）后，会给你一个地址，填进客户端的"订阅"栏：

```
http://服务器IP:8088/sub/你的令牌
```

- 客户端认不出来？用面板上的**通用地址** `/sub/你的令牌/std`，什么客户端都能导入。
- 想要配置文件？菜单 `10` 可以下载 Clash / v2rayN / 小火箭格式。
- 拉不到订阅：先放行 `8088` 端口（云服务器还要在控制台安全组放行）。

## 常见问题

**装到一半卡住 / 下载失败？**
先看是不是网络连不上 GitHub：可以看 `logs/singbox-download.log`。可以给命令挂代理，或用镜像：
```bash
SINGBOX_DOWNLOAD_MIRROR=https://ghproxy.net/ bash sb.sh
```
下载失败会立即停下，不会假装装好。

**客户端连不上，但面板显示服务正常？**
多半是 NAT / 端口映射问题，去菜单 `6` 填上"客户端实际该连的 IP 和端口"。

**升级后菜单还是老样子？**
跑一次 `sb update`。

**Alpine 上提示 `cannot execute: required file not found`？**
先跑 `sb update`；还不行就重装时选内核 `1`。

**想用 HTTP/3？**
装内核时选 `1`（最新版）或到菜单 `9 → 2` 升级。系统包版和"正式版"都太旧，不支持。

**内存小、机器卡？**
- 节点只留用得到的几个，每个协议都要吃内存。
- 不开 Argo 和订阅服务（菜单 `12` / `11`）。
- 菜单 `8 → 6` 打开低内存模式（512 MiB 以下的机器首次安装会自动开）。
- 91 MiB 这种极小机器：装内核选 `1`，脚本会自动用最省内存的方式下载。

**面板上 `%CPU` 是 0，但 `%VSZ` 显示 1000% 多，是不是要炸了？**
不是。`%VSZ` 是程序"预留"的地址空间，不等于真实占用，Go 语言写的程序都这样。看真实占用请菜单 `8` 里的内存数字。

## 卸载

菜单 `15` → 输入 `DELETE` 确认。会停掉 Argo 隧道；系统里的 cloudflared / nginx 会先问你要不要一起卸（默认不卸，以免影响别的东西）。
